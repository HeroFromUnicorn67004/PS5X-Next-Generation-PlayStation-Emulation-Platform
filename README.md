### ✨ Key Features & Architecture


* **🦀 Rust-Powered Core:** Developed using Rust for strict memory safety, zero-cost abstractions, and robust multithreading.
* **⚡ Advanced CPU & GPU Engines:** Features specialized instruction decoding, JIT compilation via LLVM, and Vulkan-based graphics translation.
* **🧠 Unified Memory Management:** Accurately models resource allocation, address spaces, and synchronization between components.
* **🔒 Secure & Stable Environment:** Fully isolated execution sandbox protecting host system files while maintaining maximum efficiency.

---

### 💻 System Requirements

To run PS5X Studio smoothly, your computer should meet the following baseline hardware specifications:

* **Operating System:** Windows 10/11 (64-bit) or modern Linux distribution
* **Processor (CPU):** Intel Core i3 (or equivalent AMD processor) / Recommended: Multi-core CPU
* **Graphics (GPU):** NVIDIA GeForce GTX 1050 Ti (or equivalent Vulkan 1.2+ compatible GPU)
* **Memory (RAM):** 8 GB minimum (16 GB+ recommended for optimal profiling)
* **Storage:** 2 GB of available space for runtime environment and caches

---

### 🔒 Safety & Reliability

PS5X is engineered as an entirely independent research and emulation workspace. It operates within a secure sandbox layer, ensuring complete safety, data integrity, and resource isolation for your host computer system. All operations are transparent and fully managed through built-in diagnostic tools.
